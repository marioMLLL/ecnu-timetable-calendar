# 📅 ECNU 课表导入日历

把华东师范大学学生管理系统里“只告诉你第几周、却不告诉你具体哪天”的课表，翻译成 macOS Calendar、Windows Outlook 和其他日历应用真正听得懂的日程。

> 告别手动数周数。毕竟我们来学校是学习的，不是参加《最强大脑：今天到底第几周》。🧠

## ✨ 能做什么

- 🔎 直接读取 `byyt.ecnu.edu.cn` 当前登录账号的课表接口
- 🗓️ 把教学周、星期和节次换算成准确日期与时间
- 🧩 支持连续周、离散周、单双周和临时调课
- ⏰ 为每节课设置提前提醒
- 📍 为普陀、闵行校区写入 Apple 结构化位置和地图链接
- 🍎 自动适配 macOS Calendar
- 🪟 自动适配 Windows Outlook / 默认日历应用
- 📱 生成二维码，用 iPhone 或 Android 手机扫码导入日历
- 🔄 生成私人订阅地址，在登录有效时自动同步调课
- 🔒 默认导入完全在本地完成；仅在主动开启订阅时上传生成后的 ICS，绝不上传学校 Cookie 或会话
- 🛟 接口读取失败时，自动尝试从页面课表兜底解析

## 🚀 安装

### 从 Release 安装（推荐）

1. 在仓库右侧打开 **Releases**，下载最新的 `ecnu-timetable-calendar-v*.zip`。
2. 解压 ZIP。
3. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
4. 开启右上角的“开发者模式”。
5. 点击“加载已解压的扩展程序”，选择刚解压的文件夹。

> 浏览器可能会郑重其事地提醒你这是开发者扩展。放心，它只是想看课表，没有兴趣接管世界。🌍

### 从源码安装

克隆仓库后，直接在扩展管理页加载仓库根目录即可。项目是原生 HTML/CSS/JavaScript，没有 `node_modules` 黑洞，也没有“先编译半小时再说”的仪式感。

## 🧭 使用

1. 登录华师大学生管理系统，打开“我的课表”。
2. 点击浏览器工具栏里的扩展图标。
3. 检查“第 1 周周一”、提醒时间和日历名称。
4. 点击 **读取并预览课程**。
5. 确认课程、周次、地点和节次。
6. 点击平台对应的 **导入到日历** 按钮，在日历应用中确认导入。

如果想把课表送进手机，则在课程读取完成后点击 **手机扫码导入**，再用相机扫码。电脑负责打包，手机负责拆包，谁也不用在微信里给自己发送 `.ics`。📦

扩展采用两段式交互：第一次点击读取课程并准备日历文件，第二次点击负责打开系统日历。这样既符合浏览器的安全规则，也避免你去下载目录里玩“大家来找 `.ics`”。🔍

## 🍎 macOS

按钮会显示为“导入到 macOS 日历”。准备完成后点击按钮，系统 Calendar 会打开导入确认窗口。

## 🪟 Windows

按钮会显示为“导入到 Outlook / 系统日历”。

- 经典 Outlook 或已经关联 `.ics` 的应用通常会直接打开导入窗口。
- 如果新 Outlook 没有自动打开，请进入 **日历 → 添加日历 → 从文件上传**，选择下载目录中刚生成的 `.ics`。
- 请确认 Outlook 的日历通知以及 Windows 的“设置 → 系统 → 通知”均已开启。

生成文件包含标准 `VALARM`、`VTIMEZONE` 和 Outlook 忙碌状态字段。也就是说，提醒不是一句“理论上支持”，而是认真写进日历文件里的。⏰

## 📱 手机扫码导入

1. 在扩展中读取并预览课程。
2. 点击 **手机扫码导入**。
3. 用 iPhone 或 Android 手机相机扫码，打开导入页。
4. 导入页会识别手机系统并显示对应操作。

### iPhone

点击 **添加到 iPhone 日历**，然后在 iOS 的日历预览中点击“全部添加”，选择目标日历。

### Android

点击 **添加到安卓日历**，在系统应用选择器中选择系统日历或其他支持 `.ics` 的日历应用。若手机无法直接处理，页面会自动下载 `.ics`，可从下载通知或文件管理器中再次打开。

> Google Calendar 安卓版目前不提供 `.ics` 批量导入入口；使用该应用时，需要在电脑网页版 Google Calendar 的“设置 → 导入和导出”中导入下载的文件。三星、小米、华为等系统日历的实际处理方式可能因系统版本而异。机器人世界尚未统一日历外交协议。🤖

一整个学期的 `.ics` 往往大到塞不进二维码，所以扩展放进去的是压缩后的课程结构。扫码打开的 GitHub Pages 页面会在手机本地还原课表并生成 `.ics`；数据位于 URL 的 `#` 片段中，浏览器不会把它发送给网页服务器。课程不出门，隐私不旷课。🔒

> iOS 不允许网页静默修改系统日历，因此最后的“全部添加”必须由你亲自确认。这不是插件偷懒，是苹果把日历门卫安排得很认真。🍎

## 🔄 私人课表订阅

读取课程后，可以设置自动删除日期并创建私人订阅。将生成的 HTTPS 地址作为“网络日历”添加到 Apple Calendar、Outlook 或其他支持 ICS 订阅的日历应用。

- 扩展在用户登录状态有效时检查课表，只有课表发生变化才上传新 ICS。
- 读取和更新使用两枚相互独立的 256 位随机令牌，不包含学号。
- 订阅服务只保存最新 ICS 和更新令牌的 SHA-256 哈希，不接收学校 Cookie、SESSION 或密码。
- 到期后自动删除，也可随时撤销或重新生成地址。
- 调课后使用稳定事件 UID，便于订阅日历更新原事件。
- 订阅事件会保留完整教室文本和地图搜索链接；已核验楼宇同时写入标准 `GEO` 与 Apple 结构化位置。未收录楼宇不会冒充校区中心，以免显示错误图钉。

Cloudflare KV 是最终一致存储：更新或撤销通常很快生效，但全球节点最迟可能约 60 秒后才全部看到新状态。日历客户端本身也按各自周期拉取订阅，因此不会像即时推送一样立刻刷新。

> 订阅地址本身就是读取凭据。拿到它的人能看到课程名称、时间和地点，请勿公开分享；如果泄露，请立即在扩展中重新生成。

## 🔐 隐私与权限

扩展只申请完成任务所需的权限：

- `activeTab` / `scripting`：读取当前课表页面
- `storage`：保存日期、提醒和日历名称设置
- `alarms`：订阅启用后定时检查课表变化
- `downloads` / `downloads.open`：生成并打开 `.ics`
- `byyt.ecnu.edu.cn`：访问学校课表接口

扩展不会把登录凭据硬编码进源码。手机扫码导入仍完全在浏览器本地处理；只有用户主动开启私人订阅时，扩展才会把生成的 ICS 上传到订阅服务。学校 Cookie、SESSION 和密码始终不会上传。请不要在 Issue 中粘贴 Cookie、Token 或完整 curl——它们不是“调试信息”，而是账号钥匙。🗝️

## 🧑‍💻 开发

要求：Node.js 20+，以及用于打包的 `zip`。

```bash
npm test
npm run package
```

- `npm test`：运行课表解析、日期换算、ICS 与清单校验
- `npm run package`：在 `dist/` 生成可发布 ZIP

核心目录：

```text
├── manifest.json
├── popup.html / popup.css / popup.js
├── api-hook.js
├── content.js
├── lib/schedule-core.js / mobile-payload.js
├── mobile/              # iPhone / Android 本地导入页
├── vendor/              # 二维码与压缩库
├── tests/
└── scripts/
```

## 🤖 GitHub Actions

- 每次 Push / Pull Request 自动执行测试并生成构建产物。
- 推送 `v*` 标签时，自动校验标签与 `manifest.json` 版本一致，并创建 GitHub Release。
- `main` 更新后自动部署手机导入页到 GitHub Pages。

```bash
git tag v1.10.0
git push origin v1.10.0
```
